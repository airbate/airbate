## 🩷 Backstage · 关于我

我是 **airbate**，全栈开发者，目前在**探月具身智能社区实习，也在创业**。关注 AI Agent、具身智能、机器人和开发者工具，喜欢把想法做成可以实际使用的产品。

平时主要写代码、做原型，从 Web 应用、自动化工作流到嵌入式硬件都会尝试。对 AI 如何参与日常工作、如何与硬件和真实场景结合尤其感兴趣，也在学习产品开发和创业过程中技术之外的事情。

代码之外，我会写 AI 科普、整理 Obsidian 知识库，记录项目里的尝试和踩过的坑。欢迎交流技术、开源项目，以及值得一起动手做的想法。
